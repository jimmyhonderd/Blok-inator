# Blok-inator

Vallende neon-blokken in "Vroeger was alles beter"-stijl met een LEDJOCKEY-tintje.

**Speel / installeer:** https://jimmyhonderd.github.io/Blok-inator/

## Installeren op Android

1. Open de link hierboven in Chrome.
2. Tik op ⋮ (rechtsboven) → **App installeren**.
3. De app staat daarna tussen je apps, start schermvullend en werkt offline.

## Besturing

- Touch: vegen links/rechts = verplaatsen, tik = draaien, veeg omlaag = zachte val, snelle veeg omlaag = harde val, veeg omhoog of tik op HOLD = vasthouden. Knoppen onderin (staand): links, draai linksom, draai rechtsom, rechts.
- Pc: pijltjes, Z/X = draaien, spatie = harde val, C = hold, P = pauze.

## Wat erin zit

- 7-bag, ghost piece, hold, muurkicks, oplopend tempo per 10 rijen, highscore op het toestel.
- Neon-blokjes in zeven kleuren, VWAB-titelscherm, "VWAB!"-flits bij vier rijen tegelijk.
- Staand (telefoon) en liggend (tablet) met HUD naast het veld.
